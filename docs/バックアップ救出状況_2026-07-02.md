## 🔥 最優先アクション: C:\Windows.old の確認（時間制限あり）

Windowsの「このPCを初期状態に戻す」の方式によっては、旧環境が
**C:\Windows.old に約10日間残る**（自動削除される）。リセットが 6/30〜7/2 なら猶予は残りわずか。

PCを操作できるようになり次第、最初に：
1. エクスプローラーで `C:\Windows.old\Users\sould\GoogleDrive\` を開く
2. 存在すれば **③の全フォルダをまず外付けドライブ等へコピー**（Driveへの再アップロードはその後）
3. 存在確認は 設定 → システム → ストレージ → 一時ファイル →「以前の Windows のインストール」の有無でも可
4. 確認が済むまで、ディスククリーンアップや大容量の書き込みは行わない

- **WSL**: `wsl --install -d Ubuntu-24.04` で新規作成 → `init_wsl_workspace.ps1` で作業環境を初期化
- **WiFiパスワード**: 主要な回線はルーター本体のラベル／スマホの保存済みネットワークから再登録
- **アプリ一覧**: 本リポジトリの `setup/install-apps.ps1`＋`restore-phase2-20260615.ps1` が代替（クラウド記録から再構成済み）
- **.claude メモリ**: 再構築。今後は `%USERPROFILE%\.claude` を定期バックアップ対象に追加
- **AppData\Roaming**: アプリ再インストールで大半は再生成される。個別データ（ブラウザプロファイル等）はクラウド同期分で復旧
