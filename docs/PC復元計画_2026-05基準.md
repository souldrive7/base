# PC設定 復元計画（基準時点: 2026年5月上旬）

PC完全リセット後のセットアップ復元の指針。Gmail・Google Drive・本リポジトリの記録から、
2026年5月上旬時点で実際に使っていたツール・サービスを洗い出し、**安全な順序**で復元するための計画書。

---

## 復元の基本方針

1. **順序を守る** — OS・セキュリティ → 認証基盤（アカウント・2段階認証）→ クラウド同期 → 開発環境 → 個別アプリ の順。認証基盤を先に固めることで、以降の全ステップが安全かつスムーズになる。
2. **インストーラーは公式サイトから最新版を取得する** — Google Drive に旧インストーラー（Cursor 2.6.14、VisualStudioSetup.exe 等）が保存されているが、これらは「何を入れていたかのリスト」としてのみ使い、実体は必ず公式配布元から最新安定版を入手する。
3. **復元しながら記録を残す** — Drive の「Templates - Setup Note.md」は空のままだった。今回のセットアップ内容をその都度メモし、次回リセット時の資産にする。
4. **入れないものを決める** — Windows Insider Program に参加していた形跡があるが、安定運用が目的なら再参加は見送りを推奨。

## Phase 3: 開発環境（本リポジトリが動くまで）

1. **Git** をインストールし、`user.name` / `user.email` を設定。GitHub（souldrive7）へは HTTPS + Git Credential Manager か SSH キー新規登録
2. **Python 環境** — Anaconda（利用実績あり）または軽量に Miniconda。仮想環境を作って本リポジトリの依存を導入:
   ```bash
   git clone https://github.com/souldrive7/base.git
   cd base
   pip install -r requirements.txt   # pandas, lightgbm, xgboost, catboost, tensorflow, optuna ほか
   ```
3. **エディタ** — Cursor（2026年3月導入、メイン利用の形跡）と Visual Studio（2026年4月導入）。いずれも公式サイトから最新版を取得
4. **Jupyter / Colab** — 分析ノートは Colab（Drive 上）にも保存されているため、ローカル Jupyter は必要になってから
5. **Kaggle** — アカウント確認（5/16 にパスワードリセット済み）。API を使う場合は `kaggle.json` を再発行し `%USERPROFILE%\.kaggle\` に配置
6. **データ再取得** — `input/train.csv` `test.csv` 等はリポジトリ外。Kaggle 等の取得元から再ダウンロード
